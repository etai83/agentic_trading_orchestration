# Markov Chain Bitcoin Trading Resources

## Knowledge

- [Paper: "A Regime-Switching Approach to Cryptocurrencies" - arXiv:2003.02324](https://arxiv.org/abs/2003.02324)
  Applies Hidden Markov Models to cryptocurrency pricing and transitions. Use for: understanding regime-switching mathematics and performance benchmarks.
- [Documentation: `hmmlearn` Python Library](https://hmmlearn.readthedocs.io/en/latest/)
  Standard documentation for fitting Gaussian Hidden Markov Models. Use for: implementation syntax and hyperparameter tuning.
- [Article: "Hidden Markov Models for Regime Detection" - QuantStart](https://www.quantstart.com/articles/hidden-markov-models-for-regime-detection-using-stat-models-in-python/)
  Excellent step-by-step introduction to HMMs in financial data using Python. Use for: constructing initial feature sets (log returns, volatility) and state initialization.
- [Documentation: `Backtesting.py` Library](https://kernc.github.io/backtesting.py/)
  A lightweight event-driven backtesting library. Use for: building the backtesting loop, calculating Win Rate, Sharpe, and Drawdowns.

## Wisdom (Communities)

- [r/algotrading](https://reddit.com/r/algotrading)
  High-signal community for quantitative trading, backtesting pitfalls, and execution details. Use for: peer review of trading strategies and transaction cost modeling.
- [r/quant](https://reddit.com/r/quant)
  Academic and professional quantitative finance subreddit. Use for: mathematical rigor checks and understanding stationarity/overfitting risks.
