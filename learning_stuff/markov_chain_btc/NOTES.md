# Working Notes & Preferences

## User Profile
- **Programming Level:** Intermediate/Experienced Python (Pandas, Numpy). Minimal syntax boilerplate needed.
- **Math/Trading Background:** Understands trading indicators and concepts; needs dedicated explanation of Markov/HMM math.
- **Goal:** Comprehensive path: learn the mathematical theory first, then apply it in a hands-on Python backtesting project.

## Teaching Strategy
- **Format:** Focus on mathematical clarity followed by interactive code blocks or Python snippets.
- **Tools:** Use standard Python libraries (`pandas`, `numpy`, `hmmlearn`, `backtesting.py` or vectorized backtests).
