# User Background and Mission Clarified

The user is an intermediate Python developer who is already comfortable with standard data science tools (Pandas, Numpy) and basic trading concepts. They want to learn the mathematics of Markov Chains and Hidden Markov Models (HMM) specifically, and then implement and backtest a regime-switching strategy in Python.

This sets a baseline where code boilerplate can be minimized, focusing teaching on:
1. Transition matrices and the Markov property.
2. Formulating states from price action/volatility.
3. Building the strategy and evaluating performance indicators (Sharpe ratio, drawdowns, win rate).
