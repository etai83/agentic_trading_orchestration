# Markov Chain Bitcoin Trading Glossary

This glossary defines the key mathematical and financial terms used in this workspace. Terms are added here once they are understood and successfully applied in our lessons.

## Terms

**Markov Property**:
The mathematical assumption that the future state of a system depends only on its current state, rendering its historical path irrelevant.
_Avoid_: Memory property, state sequence

**Transition Probability Matrix**:
A square matrix representing the probabilities of moving between states in a single step, where each row sums to exactly 1.0.
_Avoid_: Likelihood matrix, state chart
