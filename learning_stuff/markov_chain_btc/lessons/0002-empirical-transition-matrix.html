Lesson 2: Computing Transition Matrices in Python

Course: Markov Chain BTC Trading Lesson: 0002

From Math to Python

In Lesson 1, we learned that a transition matrix represents the probabilities of moving between states. Now, we will write Python code using `pandas` and `numpy` to compute an empirical transition matrix from historical Bitcoin price data.

This process has four steps:

  1. Calculate daily log returns.
  2. Discretize returns into state labels (e.g., Bull, Bear, Flat).
  3. Align today's state with tomorrow's state.
  4. Build and normalize a frequency crosstab.

Step-by-Step Implementation

Here is the Python implementation. We will compute the transition matrix from a mock dataset representing daily BTC prices:

import pandas as pd
import numpy as np

# 1. Create a dummy price series representing BTC
prices = [30000, 30500, 30100, 30200, 31000, 30400, 29900, 30300]
df = pd.DataFrame({"price": prices})

# 2. Calculate daily percentage returns
df["return"] = df["price"].pct_change()

# 3. Categorize returns into States: Bull (1), Bear (-1), Flat (0)
def categorize_state(ret):
    if pd.isna(ret):
        return np.nan
    if ret > 0.01:
        return "Bull"
    elif ret < -0.01:
        return "Bear"
    else:
        return "Flat"

df["state"] = df["return"].apply(categorize_state)

# 4. Shift tomorrow's state to align with today's row
df["next_state"] = df["state"].shift(-1)

# Drop any rows with NaN states
df = df.dropna(subset=["state", "next_state"])
print(df[["state", "next_state"]])

The resulting DataFrame shows transitions day-by-day:

  state next_state
1  Bull       Bear
2  Bear       Flat
3  Flat       Bull
4  Bull       Bear
5  Bear       Bear
6  Bear       Bull

Generating the Transition Matrix

To count the transitions and convert them to probabilities, we use `pd.crosstab` and normalize across the rows by dividing each row by its sum:

# Count transitions
transition_counts = pd.crosstab(df["state"], df["next_state"])

# Normalize by row sum to get transition probabilities
transition_matrix = transition_counts.div(transition_counts.sum(axis=1), axis=0)

print(transition_matrix)

This yields our matrix. If a transition never occurred in the historical dataset, the value will be 0.0. In real-world datasets with thousands of data points, these probabilities stabilize into powerful indicators of regime transitions.
