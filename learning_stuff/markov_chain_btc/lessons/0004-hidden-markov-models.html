The Limitations of Simple Markov Chains

In standard Markov chains, the states are directly observed and hard-coded (e.g., daily returns > 1% is "Bull"). However, financial markets rarely follow such simple, rigid boundaries. Volatility changes over time, and a +0.5% return might be considered highly bullish in a low-volatility environment, but flat or even bearish in a high-volatility crash.

To capture these shifting conditions, we use Hidden Markov Models (HMM).

What makes a Markov Model "Hidden"?

In an HMM, the underlying states (the "market regimes") are latent (unobserved). We cannot see the state directly. Instead, the hidden states generate the observable outputs (e.g., daily prices or volumes) that we actually measure.

An HMM consists of two primary probability components:

  1. Transition Probabilities: The probability of moving from one hidden state to another (e.g., transitioning from a "Quiet Bull" regime to a "Volatile Bear" regime).
  2. Emission Probabilities: The probability distribution of the observed data given a specific hidden state. In finance, this is typically modeled as a Gaussian (normal) distribution with a specific mean and variance for each state.

Fitting an HMM in Python

In Python, we use the `hmmlearn` library. Here is how we fit a 2-state HMM on a simulated return series to discover the hidden regimes:

import numpy as np
import pandas as pd
from hmmlearn import hmm

# 1. Simulate data representing two different regimes:
# Regime 0 (Quiet Bull): High mean, low volatility
# Regime 1 (Volatile Bear): Low mean, high volatility
np.random.seed(42)
regime_0 = np.random.normal(loc=0.002, scale=0.01, size=200)
regime_1 = np.random.normal(loc=-0.005, scale=0.03, size=100)
returns = np.concatenate([regime_0, regime_1])

# HMM expects a 2D array of features
X = returns.reshape(-1, 1)

# 2. Define and fit a Gaussian HMM with 2 hidden states
model = hmm.GaussianHMM(n_components=2, covariance_type="diag", n_iter=100, random_state=42)
model.fit(X)

# 3. Inspect the discovered hidden states
hidden_states = model.predict(X)

print("--- Transition Matrix Between Hidden States ---")
print(model.transmat_)

print("\n--- Discovered State Characteristics ---")
for i in range(model.n_components):
    mean = model.means_[i][0]
    variance = np.diag(model.covars_[i])[0]
    print(f"State {i}: Mean Return = {mean:.4f}, Volatility = {np.sqrt(variance):.4f}")

The model will output the transition matrix between the hidden states, and the mean/volatility characteristics it discovered for each state. The algorithm groups the data automatically, without you needing to specify hard return thresholds.
