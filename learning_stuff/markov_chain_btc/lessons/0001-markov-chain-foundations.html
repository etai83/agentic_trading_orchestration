Lesson 1: Foundations of Markov Chains in Trading

Course: Markov Chain BTC Trading Lesson: 0001

What is a Markov Chain?

A Markov chain is a mathematical model that describes a sequence of possible events. The core assumption of a Markov chain is the Markov Property (or "memorylessness"): the probability of transitioning to any future state depends only on the current state, not on the sequence of states that preceded it.

P(X_{t+1} = x_{t+1} \mid X_t = x_t, X_{t-1} = x_{t-1}, \dots, X_0 = x_0) = P(X_{t+1} = x_{t+1} \mid X_t = x_t)

In quantitative trading, we use this simplification to model regimes. Instead of looking at the entire history of Bitcoin prices, we look at the current market state (e.g., "high volatility") to estimate the probability of tomorrow's state.

Defining Market States

To apply a Markov chain to Bitcoin, we must first discretize the continuous price data into a set of distinct, mutually exclusive states. Let's start with a simple 3-state system based on daily price returns:

  • State Bull (B): Daily return is greater than +1%
  • State Bear (S): Daily return is less than -1%
  • State Flat (F): Daily return is between -1% and +1%

The Transition Probability Matrix

A transition probability matrix, denoted as P, describes the probability of moving from state i to state j in a single time step. Each row of the matrix represents the starting state, and each column represents the destination state.

Because the market must transition into some state tomorrow, the probabilities in each row must sum to exactly 1.0.

Example Matrix

Here is an example transition matrix estimated from historical BTC daily data:

From \ To
Bull (B)
Bear (S)
Bull (B)
0.45 (stays Bull)
0.55 (goes Bear)
Bear (S)
0.30 (goes Bull)
0.70 (stays Bear)

In this simplified system: if today is a Bull day, there is a 45% chance tomorrow will be a Bull day, and a 55% chance tomorrow will be a Bear day.

How This Improves Win Rate

Markov chains help us transition from static trading rules (e.g., "always buy when RSI < 30") to conditional, regime-dependent strategies. By identifying states where the transition probability is strongly skewed in our favor, we can selectively enter trades when the statistical win rate is higher.
