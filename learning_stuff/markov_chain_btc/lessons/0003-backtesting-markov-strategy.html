Lesson 3: Backtesting a Markov-Chain Strategy

Course: Markov Chain BTC Trading Lesson: 0003

From Transition Probabilities to Trading Signals

Now that we can compute a transition matrix, we can use it to build a Regime-Switching Strategy. The logic is simple: we look at today's market state, find the probabilities of tomorrow's state from our matrix, and enter a position if the probability of a bullish transition is high.

In this lesson, we will write a vectorized backtest in Python to simulate this strategy's historical performance.

The Strategy Rules

We define a simple conditional trading rule:

  • Buy / Hold: If today's state has a transition probability to a "Bull" state greater than 50% (P(Bull | Current State) > 0.50).
  • Stay in Cash: Otherwise, exit the market (no position).

⚠️ Overfitting and Look-Ahead Bias

If we calculate the transition matrix on the entire dataset and then backtest on the same dataset, we commit look-ahead bias (using future data to predict the past). In professional setups, we calculate the matrix on a rolling historical window (training set) and trade on the next period (test set).

Python Vectorized Backtest Code

Here is the code to calculate transition-dependent signals and compute cumulative returns:

import pandas as pd
import numpy as np

# 1. Create historical price series
np.random.seed(42)
dates = pd.date_range(start="2026-01-01", periods=100)
returns = np.random.normal(loc=0.001, scale=0.02, size=100) # simulated returns
prices = 30000 * np.exp(np.cumsum(returns))

df = pd.DataFrame({"price": prices, "return": returns}, index=dates)

# 2. Categorize daily states
df["state"] = "Flat"
df.loc[df["return"] > 0.01, "state"] = "Bull"
df.loc[df["return"] < -0.01, "state"] = "Bear"

# 3. Fit empirical transition matrix (using all data for demonstration)
df["next_state"] = df["state"].shift(-1)
transitions = pd.crosstab(df["state"], df["next_state"])
transition_matrix = transitions.div(transitions.sum(axis=1), axis=0)

print("--- Transition Matrix ---")
print(transition_matrix)

# 4. Map states to Buy/Sell signals (1 = hold, 0 = cash)
# We buy if the transition probability to Bull from current state is > 35% (using a lower threshold for simulated noisy data)
bull_probabilities = transition_matrix["Bull"].to_dict()
df["prob_to_bull"] = df["state"].map(bull_probabilities)

# Shift signal by 1 day because signal generated today is traded tomorrow
df["signal"] = (df["prob_to_bull"] > 0.35).astype(int).shift(1).fillna(0)

# 5. Compute strategy returns
df["strategy_return"] = df["signal"] * df["return"]

# 6. Performance evaluation
cumulative_market = np.exp(np.cumsum(df["return"])) - 1
cumulative_strategy = np.exp(np.cumsum(df["strategy_return"])) - 1

win_rate = (df.loc[df["signal"] == 1, "return"] > 0).mean()

print(f"\nFinal Buy & Hold Return: {cumulative_market.iloc[-1]:.2%}")
print(f"Final Strategy Return: {cumulative_strategy.iloc[-1]:.2%}")
print(f"Strategy Win Rate: {win_rate:.2%}")
